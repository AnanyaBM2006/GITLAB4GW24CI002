##  3rd Semester Mini Project
### **PRIORITY QUEUE FOR TASK SCHEDULING USING PYTHON**

This mini project implements a task scheduling system using the concept of a **Priority Queue**.

###  Concepts Implemented
- **DSA:** Priority Queue for efficient task management  
- **Operating Systems:** Task Scheduling principles  
- **Object-Oriented Programming (OOP):**
- Classes and Objects
- Encapsulation
- Modular and structured design

###  Project Description
The system schedules tasks based on their priority, ensuring that higher-priority tasks are executed before lower-priority ones.  
This project simulates real-world CPU task scheduling and demonstrates the integration of DSA and OS concepts using Python with object-oriented design.
